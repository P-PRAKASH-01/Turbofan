# ENGINE-TWIN — Pilot Cockpit & Aero-Piston Engine Simulation Frontend

**Directory:** `frontend/`  
**Framework:** React 18, Vite 5, TypeScript 5, Tailwind CSS, Recharts, Lucide-React, Vitest  
**Status:** Implemented, Fully Bundled & Tested (17 Vitest tests passing)  

---

> [!IMPORTANT]
> **SIMULATION-FIRST RESEARCH DISCLAIMER**

> These indicators **do not** represent physical FAA/EASA certified airworthiness telemetry or physical engine avionics.

## 1. Features & Dual-Tab Layout

The application provides a pilot-style aero-piston digital twin cockpit designed around aviation dark-theme principles:

### Tab 1 — Engine Cockpit (Primary Operational View)
- **Primary Dial Instruments**:
  - **RPM** (0–5500 RPM with caution/redline zones)
  - **Throttle Lever Command** (0–100%)
  - **Cylinder Head Temperature (CHT)** (20–260 °C with caution/warning zones)
  - **Exhaust Gas Temperature (EGT)** (100–950 °C)
  - **Oil Temperature** (20–150 °C)
  - **Oil Pressure** (100–700 kPa)
  - **Fuel Flow** (0.5–25.0 g/s)
  - **Manifold Pressure** (20–110 kPa)
  - **Structural Vibration** (0.05–3.5 g RMS)
- **Digital Twin Health Indices**:
  - **EHI Radial Gauge (0–100)**: Color-coded into 4 status bands (Band 1 Nominal ≥90, Band 2 Acceptable 75–89, Band 3 Degraded 50–74, Band 4 Critical <50) with an automatic failsafe gate when telemetry coverage < 80% or RPM drops out.
  - **Dual-Scale SDQI Card**: Simultaneous reporting of Composite SDQI (telemetry array health) and Worst-Channel SDQI (single-sensor fault isolation) with individual $q_i$ channel pills.
- **Flight Simulator Controls**:
  - Validated command inputs for Throttle (20–98%), Governor Target RPM (750–5200 RPM), Altitude (0–5000 m), Ambient Temperature (-10 to 45 °C).
  - Playback controls: Start, Pause / Resume, Reset, Seek slider (0–120s), Playback speed (0.5×, 1.0×, 2.0×, 5.0×).
  - Quick scenario selector and quick fault triggers.
- **Telemetry Matrix (Measured vs Digital Twin Reference)**:
  - Compares raw sensor reading ($Y_{\text{meas}}$) against the dynamic healthy reference ($\hat{Y}_{\text{ref}}$) and standardized residual distance.
- **Time-Series Analytics (6 Labelled Recharts)**:
  1. RPM & Throttle dynamics over time.
  2. Thermal profile (°C): CHT, EGT, Oil Temp.
  3. Pressures (kPa): Oil vs Manifold Pressure.
  4. Fuel Metering (g/s) & Structural Vibration (g RMS).
  5. Digital Twin Health Indices (EHI, Composite SDQI, Worst-Channel SDQI).
  6. 8-Class Fault Classifier Posterior Probability Spectrum.
  - Controls: Time window (30s, 60s, 120s, All), series toggles, pause/freeze, clear history.
- **AI Fault Diagnostics Panel**:
  - Random Forest active fault classification with confidence percentage.
  - 8-class probability distribution.
  - Alert level policy (Nominal, Advisory, Caution, Warning) with interactive operator acknowledgment.
  - Neutral RUL status banner ("Not available in this version / Uncalibrated").

---

### Tab 2 — Piston Engine Simulation (Engineering Test Bench)
- **Kinematic 2D Piston Engine Schematic**:
  - 4-stroke cycle animation (Intake, Compression, Power, Exhaust) kinematically linked to simulated RPM.
  - Cylinder wall with air-cooling fins.
  - Reciprocating piston with piston rings and wrist-pin.
  - Oscillating connecting rod and rotating crankshaft counterweight.
  - Intake and exhaust valves opening and closing.
  - Spark flash during combustion power stroke.
  - Dynamic thermal heat glow on cylinder head proportional to CHT/EGT.
  - Structural vibration shake effect when vibration > 0.8g RMS.
- **Fault Injection Suite (Ground Truth vs Model Prediction)**:
  - Injects all 8 dataset-supported fault types (`normal`, `combustion_irregularity`, `thermal_abnormality`, `efficiency_degradation`, `sensor_bias`, `sensor_drift`, `sensor_stuck`, `sensor_dropout`).
  - Severity selector (Level 1 Mild, Level 2 Moderate, Level 3 Severe).
  - Target sensor channel selector for sensor faults.
  - Immediate or timed onset.
  - **Side-by-side ground truth vs AI prediction comparison**: displays simulated ground truth separately from model prediction to evaluate detection accuracy.
- **Chronological Simulation Event Timeline**:
  - Records simulation start, reset, condition changes, fault onsets, and alert triggers with exact simulation timestamps ($t=0.0\text{s}$, etc.).
  - Severity level filter (All vs Warnings/Critical only).

## 4. Mock vs. Real Digital Twin Capabilities

| Feature | Local Browser Adapter | Live FastAPI Backend Mode | Notes |
|---|---|---|---|
| **Physics Model** | Exact analytical formulas from `generate_dataset.py` | Python simulator generator | Evaluates displacement, air flow, fuel flow, and power |
| **Thermal Dynamics** | Causal first-order discrete lag ($\tau=25\text{s}, 60\text{s}$) | Causal discrete lag | Matches `CausalThermalFilter` from Phase 4C |
| **EHI (0–100)** | Heteroscedastic throttle scaling & failsafe coverage gate | Exact Phase 4C Refined System | Nulls score if coverage < 80% or RPM fails |
| **SDQI** | Dual-scale Composite + Worst-Channel ($q_i$) | Exact Phase 4C Refined System | Plausibility checks use `phase4c_refined_config.json` |
| **Fault Diagnosis** | 8-class probability estimator | Fitted Balanced Random Forest (`models/*.joblib`) | Posterior probabilities across 8 classes |
| **RUL Prognostics** | Explicitly disabled ("Not available in this version") | Explicitly disabled | Awaiting future validated degradation models |
