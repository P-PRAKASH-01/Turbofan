# Reusable UI Components

Reusable UI primitives:
- `GaugeRadial.tsx`: Radial gauge for EHI and SDQI with threshold coloring
- `MetricCard.tsx`: KPI cards with trend indicators and status badges
- `TimeSeriesChart.tsx`: Real-time streaming strip chart comparing measured vs. reference
- `StatusBadge.tsx`: Severity-coded pill badges (NOMINAL, ADVISORY, CAUTION, WARNING)
- `PlaybackControls.tsx`: Play/Pause/Seek/Rate controls for digital twin playback
